Google Sheet Sync

This connects the app to your live Google Sheet via a small Apps Script Web App bound to it, so every TA scanning through this same link writes into the same spreadsheet. One-time setup (any TA can do it):

  1. Open your sheet: open the Extensions menu → Apps Script.
  2. Delete any placeholder code, paste in the Code.gs file provided alongside this app.
  3. Click Deploy → New deployment → type "Web app" → Execute as "Me" → Who has access "Anyone with the link" → Deploy.
  4. Authorize it when prompted (it's your own script on your own sheet).
  5. Copy the /exec URL it gives you and paste it below, then Save.

Once saved, use the Sync to Google Sheet button on the Records tab any time to push all not-yet-synced scans straight into your live spreadsheet — it adds a new date column, marks P/A per student, and appends every scan to an "Attendance Log" tab. The local Export button still works too, for an offline backup copy.
